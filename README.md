# 🖱️ AI Gesture-Controlled Mouse & Scroller

A real-time computer vision application that allows you to control your computer's mouse cursor and scroll wheel using hand gestures. Built with Python, OpenCV, and the MediaPipe Tasks API.

## ✨ Features
* **Fist:** Move the mouse cursor smoothly across the screen.
* **Point (Index Finger Up):** Enter scroll mode. Move your finger above or below the on-screen dead-zone to scroll up or down.
* **Open Palm:** Pause all tracking and interactions.
